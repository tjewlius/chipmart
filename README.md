# Chipmart

## Overview
This is a full-stack e-commerce application built with Ruby on Rails as a learning project.

### The goal is to deeply understand:

1. Rails MVC architecture
2. Database design & associations
3. Real-world business logic (cart → order → checkout)
4. Authentication & authorization
5. Scalable app structure
6. Project Goals

### By the end of this project, I should be able to:

1. Design relational data models confidently
2. Build full CRUD flows in Rails
3. Handle sessions and state (cart system)
4. Implement authentication and authorization
5. Manage multi-step workflows (checkout)
6. Structure a production-ready Rails app
7. Deploy a Rails application with a custom domain and SSL

## Tech Stack

- Ruby on Rails
- PostgreSQL
- CSS
- Payment processor integration --- Stripe or Pesapal or any alternative I figure out with time.
